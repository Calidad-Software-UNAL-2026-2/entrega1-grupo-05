# Paso 2.2 — Necesidades del Negocio

_El porqué de alto nivel del proyecto: qué problema de negocio resuelve._

| ID | Necesidad |
| :-- | :--- |
| N-1 | Centralizar y automatizar la planificación y ejecución de auditorías contables internas y externas para reducir tiempo, esfuerzo manual y dependencia de procesos dispersos. |
| N-2 | Importar y analizar información financiera procedente de software contable para identificar inconsistencias, hallazgos y desviaciones con mayor precisión. |
| N-3 | Conservar trazabilidad de usuarios, acciones y decisiones realizadas durante una auditoría para garantizar integridad, rendición de cuentas y revisión posterior. |
| N-4 | Gestionar usuarios, roles y permisos desde una plataforma centralizada para controlar responsabilidades y prevenir acciones no autorizadas. |
| N-5 | Generar informes claros y personalizados sobre los hallazgos para apoyar la toma de decisiones gerenciales y financieras. |
| N-6 | Proporcionar gráficos y métricas de auditoría para evaluar el estado financiero y comunicar resultados a propietarios, directores y demás interesados. |
| N-7 | Mejorar la confiabilidad, seguridad, disponibilidad y accesibilidad del proceso de auditoría contable. |
| N-8 | Integrar o intercambiar información con software contable, preferiblemente mediante API y manteniendo la carga manual como alternativa para pruebas y revisión. |

**Resultado esperado del proyecto:** reducir al menos el 30 % el tiempo de auditoría y al menos el 20 % los errores reportados respecto de los procesos manuales.
